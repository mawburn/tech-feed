# Game engineering, realtime simulation, rendering and anti-cheat

Today's rotation from the engineering-blog catalog. Check for **new** posts (within the window) on a few of these, plus anything relevant outside the list. Read the post itself, not the index page, and check its publication date against any incident date. Being listed gives no priority: a post is chosen only for technical substance and current relevance.

**Riot/VALORANT are particularly useful examples of the desired depth.** Technical posts about tick rate, network replication, hit registration, lag compensation, server load, anti-cheat, shader implementation, debugging and performance can be significant without describing a new game release. Avoid equating player-facing patch notes or promotional dev diaries with engineering investigations.

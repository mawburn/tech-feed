Major Cloud Outage Traced to Hidden Kernel Spinlock in BPF Network Telemetry Subsystem

A cascade failure across western European hyperscaler regions yesterday originated from an unreleased Linux 6.8 patch backport. Under rare burst load, eBPF programs monitoring socket teardowns triggered a preemptible kernel lock contention, causing packet drops across the internal routing plane.

Why It Matters

Highlights growing architectural friction between modern kernel observability agents and mission-critical network throughput. Engineering teams are urgently auditing eBPF maps for preemptible locks.

via Postmortem & LKML489

Technical Root Cause

The lock was triggered inside bpf_sock_ops callback routines where an updated socket lookup table shared cache lines across cores, resulting in an L3 cache coherency storm.
